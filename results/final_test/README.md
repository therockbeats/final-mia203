# Evaluación final de M2

Las curvas y la matriz de confusión proceden de `val.py` de YOLOv5 v7.0 aplicado al checkpoint M2 seleccionado por validación. El conjunto contiene 508 imágenes, 400 personas y 888 armas.

Las métricas globales son Precision 0,875, Recall 0,780, mAP@0.5 0,845 y mAP@0.5:0.95 0,659. La tabla por clase está en `../final_summary/final_test_metrics.csv`.
